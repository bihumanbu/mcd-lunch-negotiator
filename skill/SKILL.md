# 拼单谈判官

## 何时用

- 用户要替一群人（2 人以上）点麦当劳午饭 / 下午茶
- 用户问「怎么点最划算」「套餐值不值」「这几个人怎么凑单」
- 用户要在某个预算约束下给团队配餐
- 用户想对比「单点」和「套餐」的真实价差

## 前置条件

麦当劳 MCP Token，二选一配置：

```bash
# 方式 A：环境变量
export MCD_MCP_TOKEN="your_token"

# 方式 B：私有凭据文件
mkdir -p ~/.workbuddy/credentials
echo '{"token":"your_token"}' > ~/.workbuddy/credentials/mcd-mcp.json
```

Token 申请：https://open.mcd.cn/mcp → 手机号登录 → 控制台 → 激活 → 复制。
Token 绑定麦当劳会员账号，**绝不写入任何仓库或公开文件**。

## 怎么跑

```bash
python src/negotiator.py <城市> <门店关键词>
```

例：

```bash
python src/negotiator.py 深圳 科技园
```

- 第一个参数是城市（如 `深圳` / `北京` / `上海`）
- 第二个是门店关键词（商圈、写字楼、地铁站名）
- **两个参数必须同时给**，只给一个会报 600058（服务端限制）

结果同时打印到终端并写入 `plan.md`（在技能上一级目录）。

首次运行约 1—2 分钟（约 100 次 MCP 调用，8 线程并发）；
之后有磁盘缓存（`data/cache_*.json`），通常 10 秒内出结果。

## 定制人群

编辑 `scripts/negotiator.py` 里的 `PEOPLE_DEFAULT`：

```python
PEOPLE_DEFAULT = [
    {"name": "老王", "budget": 40, "want": ["汉堡"], "avoid": ["鸡肉"]},
    {"name": "小林", "budget": 30, "want": ["鸡肉"], "light": True},
    {"name": "Lily", "budget": 40, "want": ["咖啡"]},
]
```

| 字段 | 含义 |
|---|---|
| `budget` | 预算上限（元） |
| `want` | 想吃的分类：`汉堡` / `鸡肉` / `牛` / `咖啡` / `小食` / `清淡` |
| `avoid` | 忌口，命中直接排除 |
| `light` | 减脂模式，优先 500 大卡以下分类 |

## 输出结构

1. **核心结论**——同样这些吃的，逐个单点买 vs 套餐组合买，差多少钱、差多少百分比
2. **每人买法**——谁吃什么、实付多少、是否满足预算与忌口
3. **优惠券叠加**——账户里的券挂在哪一单、用券后多少钱（一单只能用一张券）
4. **逐项明细**——每个套餐的「套餐价 / 同内容单点价 / 差额」，官方计价实测
5. **怎么下这几单**——拆单清单，谁跟谁合并

## 必须遵守的边界

1. **不做自动下单、不做自动支付**。输出方案和支付链接，支付由人扫码。
2. **不猜价**。任何价格必须来自 `calculate-price`；拿不到就标注「无法对照」，不许估算。
3. **套餐专属 SKU 不能当免费**。可乐中杯这类单点返回 0 的商品，要用同档位可单点商品估值，并在输出里写明。
4. **一单只能用一张券**。券的分配按「一单一张」处理。

## 关键实现细节（改代码前必读）

| 坑 | 表现 | 处理 |
|---|---|---|
| `city` + `keyword` | 只传一个报 600058 | 两个都传 |
| 批量计价 | 混入无效 SKU，`price` 返回 0 而非报错 | 逐个 SKU 单独计价 |
| 菜单目录 | 只给 `code + tags`，无名称无价格 | 逐个 `query-meal-detail` 补 |
| 单位 | 计价返回「分」，菜单/订单返回「元」 | 统一用 `fen_to_yuan()` |
| 响应格式 | 说明文档 + JSON 混排 / Markdown / TOON | 用 `parse_response()` 分形态解析 |
| 计价字段名 | `items[].productCode` 不是 `code` | 照此传参 |

完整记录见仓库 `MCP_INTEGRATION.md`。

## 定时触发（推荐用法）

在 WorkBuddy 里创建每天 11:25 的自动化，让它在午饭前把方案跑出来。这就是这个技能最合适的形态：
人还没开始纠结吃什么，清单已经躺在那里了。
